Ajout de votre nouveau logo Jolof'Era

1) Placez votre logo principal ici:
   public/brand/logo-full.png
   - Recommande: PNG transparent
   - Taille conseillee: hauteur 80 a 120 px

2) Placez votre icone (carre) ici:
   public/brand/logo-icon.png
   - Recommande: PNG 512x512

Le site remplacera automatiquement l'ancien logo si ces fichiers existent.
Si un fichier manque, l'ancien logo reste affiche (fallback).

Pour Google (favicon / resultat de recherche), remplacez aussi:
- public/favicon.svg
- public/favicon-16x16.png
- public/favicon-32x32.png
- public/favicon-48x48.png
- public/apple-touch-icon.png
- public/icons/icon-192.png
- public/icons/icon-512.png
