# Jolof'Era Demo Export

Ce dossier contient une demo publicitaire verticale de Jolof'Era basee sur tes captures.

## Ouvrir l'apercu

1. Lance [open-demo.ps1](/c:/Users/HP/Downloads/FlashRV-main/FlashRV-main/frontend/flashrv-react/styleflowdemo-export/open-demo.ps1)
2. La page s'ouvre dans Edge ou Chrome
3. Clique sur `Exporter en WebM`
4. Attends la fin du rendu puis recupere `jolofera-demo-promo.webm`
